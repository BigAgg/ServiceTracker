# users – Menü „Benutzer“

Dialog **Benutzerverwaltung** (Poweruser): Benutzer suchen/anlegen, Poweruser-Flag,
Abteilungen hinzufügen/entfernen, Benutzer entfernen (nicht sich selbst). Der in
`bootstrapAdmin` konfigurierte Benutzer ist immer Poweruser.

**Dateien:** `users.bin` (Format v1).

**Code:** `app/src/modules/users/`, Logik `core/include/st/users/user_store.h`.
